# AutoConnect — Automotive Marketplace

A responsive multi-page automotive marketplace prototype built with HTML, CSS and vanilla JavaScript.

## Run in VS Code

**Option A — no dependencies**
1. Extract the ZIP file.
2. Open the `AutoConnect` folder in VS Code.
3. Open the integrated terminal.
4. Run `node server.js`.
5. Visit **http://localhost:5173** in your browser.

**Option B — Live Server**
1. Install the VS Code extension named **Live Server**.
2. Right-click `index.html`.
3. Select **Open with Live Server**.

## Included features
- Cinematic opening screen with brand reveal and enter button.
- Responsive home page and navigation.
- New/used vehicle inventory, search and filters.
- Vehicle comparison (up to three cars).
- Test-drive request form.
- Car rental request form with duration and date fields.
- Sell-your-car submission form.
- Workshop discovery and service appointment booking.
- Customer account area with bookings, listings and service history.
- Demo sign-in / registration.
- Business dashboard with inventory, bookings, customers and add-vehicle form.
- Local browser persistence through `localStorage`.

## Important prototype notes
This is a working front-end competition prototype. Forms, demo accounts, listings and bookings save in the current browser using `localStorage`. It does **not** yet have a production backend, secure authentication, payment gateway, SMS/email notifications, live dealer feeds or real workshop integrations. Do not use real passwords or sensitive personal information in the demo.

Vehicle photography is loaded from Unsplash, and Google Fonts are loaded online. An internet connection is needed for those remote assets. The site itself runs locally.
